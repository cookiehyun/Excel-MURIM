# Excel MURIM

엑셀 VBA로 만든 실시간 2D 무협 격투 게임 (Windows 엑셀 `.xlsm` 전용. 맥 엑셀에서는 동작하지 않음)

## 시작하기

처음 한 번만 세팅하면 된다. 자세한 단계별 안내: [docs/SETUP_KO.md](docs/SETUP_KO.md)

1. 엑셀에서 새 통합 문서를 만들고 `src/`와 같은 폴더에 `ExcelFighter.xlsm`으로 저장한다.
   (OneDrive 동기화 폴더는 피하고 로컬 경로를 쓴다.)
2. 파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정 →
   **"VBA 프로젝트 개체 모델에 안전하게 액세스할 수 있음"**을 켠다.
3. Alt+F11 → 파일 > 파일 가져오기 → `src/DevTools.bas`
4. Alt+F8 → `DevTools.ImportSrc` 실행 (나머지 모듈을 가져온다)

**업데이트할 때마다:** `git pull` → Alt+F8 → `ImportSrc` → (VBE) 디버그 > VBAProject 컴파일

**실행:** Alt+F8 → `StartGame`

## 게임 모드

시작 화면에서 ↑↓로 고르고 A로 결정한다.

| 모드 | 내용 |
|---|---|
| ARCADE | 캐릭터 → 난이도 → 나머지 5명과 차례로 대결 → 최종 보스 **천마** → 엔딩 |
| VS CPU | 내 캐릭터와 상대, 난이도, 무대를 골라 한 판 대결 (3판 2선승) |
| TRAINING | 타이머 없음, 콤보가 끝나면 체력 회복, 게이지 항상 MAX |

**아케이드**
- 상대 5명은 무작위 순서, 4번째 상대부터 CPU가 한 단계 강해지고 보스는 항상 HARD
- 지면 CONTINUE? 9→0 (A = 같은 상대와 재도전, S = 포기 → GAME OVER)
- 천마: 체력 1400, 흑림 계열 기술 강화판 (마공탄, 순간이동, 궁극기 "CHEONMA MUHWANG")

**라운드 (VS CPU · 아케이드)**
- 60초 타이머, KO 또는 TIME(체력 비율이 높은 쪽 승리), 먼저 2승하면 승리
- 게이지는 다음 라운드로 이어진다

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↑ | 점프 |
| ↓ | 앉기 |
| A / S / Z / X | 약P / 강P / 약K / 강K (↓ 누르고 = 앉아 공격, 점프 중 = 공중 공격) |
| A + Z 동시 (근접) | 잡기 (잡힌 직후 A + Z = 잡기 풀기, 일반 잡기만) |
| 뒤로 (상대가 공격 중일 때) | 가드. 앉은 킥(하단)은 앉아서, 점프 공격은 서서 막아야 함 |
| →→ / ←← | 대시 / 백대시 |
| Esc | 경기 중 = 일시정지 메뉴, 시작 화면 = 게임 종료 |

- 메뉴에서는 A = 결정, S = 뒤로
- 경기 중 다른 창을 클릭하면 자동으로 일시정지된다 (S 또는 RESUME으로 재개)
- 게임 중에는 셀을 클릭할 수 없다 (게임을 끝내면 풀림)

## 캐릭터 (6명 + 보스)

P = A 또는 S, K = Z 또는 X, → 는 상대 쪽. 궁극기는 게이지 MAX에서 ↓→↓→ + 버튼.

| 캐릭터 | 스타일 | 필살기 1 | 필살기 2 | 궁극기 |
|---|---|---|---|---|
| 단우 | 올라운더 | ↓↘→P 청풍장 (장풍) | →↓↘P 학비상 (무적 대공) | ↓→↓→P 천풍만장 (5연타 장풍) |
| 철산 | 잡기 | →↓←P 금강파쇄 (커맨드 잡기) | ↓↘→P 철산고 (돌진) | ↓→↓→P 나한복마 (4연타 후 내리꽂기) |
| 무영 | 검객 | ↓↘→P 검기 (칼바람) | ↓↙←P 섬광참 (돌진 베기) | ↓→↓→P 만검귀종 (난도질) |
| 설화 | 스피드 킥 | ↓↙←K 연환비각 (3연타 돌진) | →↓↘K 선풍각 (공중제비 대공) | ↓→↓→K 낙화유수 (연속 차기) |
| 흑림 | 견제 | ↓↘→P 흑사침 (독침) | ↓↙←K 귀영보 (등 뒤로 순간이동) | ↓→↓→P 천마강림 (순간이동 장법) |
| 홍련 | 부채 무희 | ↓↘→P 부채 던지기 (부메랑) | →↓↘K 연화선 (회전 연꽃차기) | ↓→↓→P 홍련업화 (상대 발밑 불기둥) |
| 천마 (보스) | 아케이드 전용 | ↓↘→P 마공탄 | ↓↙←K 순간이동 | ↓→↓→P 천마무황 |

- 게이지는 때리거나 맞으면 찬다
- 필살기는 가드해도 깎기 데미지가 들어간다
- 상대 공격이 나오는 중에 맞히면 COUNTER (데미지·경직 증가)
- 3타째부터 콤보 데미지가 10%씩 줄어든다

## 콤보

헤드리스 테스트로 들어가는 것을 확인한 콤보. 연결 규칙: 약공격(A·Z, 앉아 A·Z)은 다음 일반기로 체인(최대 3), 일반기가 맞거나 가드되면 필살기·궁극기로 캔슬.

| 캐릭터 | 입력 | 타수 / 데미지 |
|---|---|---|
| 단우 | A → A → S | 3 / 141 |
| 단우 | ↓Z → ↓X (다리 쓸기, 다운) | 2 / 120 |
| 단우 | S → ↓↘→ + S (청풍장) | 2 / 160 |
| 단우 | A → A → ↓↘→ + S | 3 / 123 |
| 단우 | 점프 X → (착지) A → S | 2~3 / 170 |
| 단우 | S → ↓→↓→ + S (궁극기) | 5 / 294 |
| 철산 | A → S | 2 / 160 |
| 철산 | ↓Z → ↓X (다리 쓸기, 다운) | 2 / 150 |
| 철산 | S → ↓↘→ + S (철산고, 다운) | 2 / 240 |
| 철산 | A → A → ↓↘→ + S | 3 / 183 |
| 철산 | ↓→↓→ + A (궁극기 나한복마) | 5 / 380 |

밸런스: CPU끼리 측정한 전체 승률 44~54% ([docs/BALANCE.md](docs/BALANCE.md)).

## 개발자용

### 문제가 생겼을 때

- 엑셀이 입력을 받지 않게 되면 VBE 직접 실행 창(Ctrl+G)에 `GameLoop.RestoreExcel`
- 상태 표시줄에 `FPS | ticks/s | paint calls/frame | render ms/frame`이 표시된다

### 디버그 키 (훈련장)

| 키 | 동작 |
|---|---|
| Tab | 조작 캐릭터 전환 (1P <-> 2P) |
| D | 상대 전환: CPU → 가만히 → 가드 더미 → 공격 더미 |
| H / J | 상대 피격 / 다운 모션 강제 재생 |
| F1 | 판정 박스 표시 (초록 = 피격 판정, 빨강 = 공격 판정) |

전체 도트 확인: Alt+F8 → `ShowGallery`

### 데이터 수정

- 기술별 발생/지속/후딜/데미지/판정 박스: `data/moves.txt` (코드 수정 불필요)
- `data/`의 스프라이트·배경·이펙트는 생성기 출력물이라 직접 고치지 않는다.
  포즈나 색을 바꾸려면 `tools/`의 스크립트를 고친 뒤 다시 생성한다 (`python tools/gen_sprites.py`).
- 필살기의 여러 프레임 모션은 `tools/gen_sprites.py`의 `MOVE_ANIMS`
  (`<기술>_pre` 발생 / `_seq` 지속·공중 / `_rec` 후딜)
- `.bas` 파일은 ASCII만 쓴다. VBE가 시스템 코드페이지(CP949)로 읽기 때문에 한글 주석은 깨진다.
- VBE에서 코드를 직접 고쳤다면 `ExportSrc`를 실행한 뒤 커밋한다.

### 헤드리스 테스트 (엑셀 없이)

`src/*.bas`를 LibreOffice의 VBA 호환 모드로 그대로 실행한다. 키 입력은 스크립트(`tools/harness/scripts/*.txt`)로 대신하고,
결과는 `tools/harness/out/<이름>.log`(틱별 상태)와 `.gif`(화면)로 나온다. 엑셀 속도와 실제 키 입력은 검증하지 못한다.

```
python3 -I tools/harness/run_harness.py            # 전체 시나리오
python3 tools/harness/strip.py combo 8 9 10 22      # 특정 틱 화면을 PNG로
python3 tools/lint_vba.py                           # 호환 검사
```

호환 규칙 (`lint_vba.py`가 검사):
- 모듈 수준 선언(Const, 변수)은 첫 프로시저보다 위에 둔다 (엑셀 컴파일 오류)
- Collection은 `.Item(key)`로 조회
- 한 줄 If의 양쪽에 인자 있는 Sub 호출 금지
- 괄호로 시작하는 Sub 인자 금지
- 함수 반환형 `As String()` 대신 `As Variant`
- `Font`, `Scale`, `Line`, `Input` 같은 엑셀 예약어를 모듈·변수 이름으로 쓰지 않는다
